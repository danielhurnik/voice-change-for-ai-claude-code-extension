# voice-change-for-ai-claude-code-extension

A funny voice changer for AI text-to-speech. Type text, pick a ridiculous
voice — Demon Overlord, Helium Chipmunk, Dalek, Movie Trailer Guy — and the
AI says it. Export the result as a WAV and ruin your group chat.

**Status: brainstorming.** Nothing built yet. The ideas, the tech options and
the plan live in [BRAINSTORM.md](BRAINSTORM.md).

## The idea in one line

TTS gives you a clean, polite AI voice. This project takes that voice and does
terrible, hilarious things to it with a real-time audio effect chain — entirely
in the browser, for free.

## Likely stack (to be decided — see BRAINSTORM.md)

Vite · React · TypeScript · Web Audio API · in-browser neural TTS (Piper or
Kokoro via WASM) · GitHub Pages

Zero servers, zero API keys, zero running costs.
